# 🌼Atenuación de Rayos Gamma en tejidos biológicos

Este proyecto implementa una simulación computacional en Geant4 (C++) para estudiar la atenuación de rayos gamma en materiales biológicos como músculo, hueso y agua.
El análisis de los datos se realiza en ROOT, comparando la intensidad transmitida y la energía depositada con la teoría de atenuación exponencial.

__*Aplicaciones:*__
1. Imagenología médica nuclear.
2. Protección radiológica contra blindajes.

## 🌷Objetivos 
- Simular la interacción de *rayos gamma* en tejidos biológicos.
- Comparar resultados con valores teóricos de atenuación.
- Explorar la variación con distintos espesores y materiales.
- Generar una base para futuros estudios de blindaje y protección radiológica.

## 🍄Requisitos 
#### Software necesario 
- Geant4 (Version )
- ROOT (Version )
- CMake ≥ 3.8
- Compilador c++
